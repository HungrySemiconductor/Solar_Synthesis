## 十六、ISP与AIA工程状态参数

这一部分主要为AIA内部电子学与快门控制参数，包括：

* ISP数据包时间
* 图像状态编号
* 曝光控制参数
* 滤波轮位置
* 快门编码器
* 自动曝光控制（AEC）
* 导星望远镜太阳矢量
* 图像序列控制参数
* 历史直方图统计

典型参数包括：

| 参数                | 中文说明      |
| ----------------- | --------- |
| ISPSNAME          | ISP数据系列名  |
| ISPPKTIM          | 数据包时间     |
| AIMGOTS           | 图像OBT时间   |
| AIFCPS            | 滤波轮位置     |
| AECMODE           | 自动曝光模式    |
| AIAWVLEN          | 波段编号      |
| AIMGSHEN          | 快门编码器     |
| AGT1SVY / AGT1SVZ | 导星望远镜太阳向量 |

## 十八、COMMENT说明

COMMENT字段说明：

* FITS文件支持长字符串关键字
* 使用HEASARC的CONTINUE规范
* 长字符串通过多个CONTINUE关键字拼接保存
