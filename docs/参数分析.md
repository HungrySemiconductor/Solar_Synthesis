- 输入

  | 文件格式  | 作用               | 内容格式                                                     | 关键提取信息                                                 | 在项目中的角色                                               |
  | --------- | ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
  | .FITS     | 太阳图像标准格式   | Header + Data                                                | • DSUN_OBS（SDO到太阳距离）<br>• RSUN_OBS（太阳像素半径）<br>• CRPIX1/CRPIX2（参考中心）<br>• DATE-OBS（观测时间）<br>• CDELT1/CDELT2（像素比例尺） | **基准参考**<br>提供"标准距离下太阳该多大"的标尺             |
  | .NetCDF   | 时间叠加的科学数据 | 多维数组 + 元数据<br>（时间、空间坐标）                      | • 图像数据（变量名待确认）                                   | **待处理的图像**<br>这些图像已经被归一化，太阳大小一致<br>需要你"拉伸"它们来模拟距离变化 |
  | .txt/.csv | 卫星轨道轨迹       | Time (YYYY-MM-DD)<br>x (km)<br>y (km)<br>z (km)<br>Derivative x (km/sec)<br>Derivative y (km/sec)<br>Derivative z (km/sec) | • 时间序列<br>• 卫星位置 (x, y, z)<br>• 可计算：<br>&nbsp;&nbsp;D_hypo = √(x²+y²+z²)<br>• 速度分量（用于验证） | **缩放因子的来源**<br>通过距离反比关系计算缩放因子：<br>Scale = D_reference / D_hypo |
