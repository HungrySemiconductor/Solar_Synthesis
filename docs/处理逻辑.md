## 处理逻辑

```
                          程序启动
                轨道数据清洗，筛选出在成像窗口内(0.5-1AU、4.7AU)7组数据

                （初始化：成像窗口时间段设定?）
                             │
                             ▼
              [ 读入唯一的一对 FITS / NetCDF 到内存 ]
              [ 提取FITS文件中基准参数并转换单位: D_SDO = DSUN_OBS / 1000 与 RSUN_OBS ]
                             │
                             ▼
                     遍历SPO轨道数据
                (以未来时间轴为主线，逐行读取)
                             │
                             ▼
               检查: 当前未来时间在成像窗口内吗?
                             │
                     ┌───────┴───────┐
                    [否]            [是]
                     │               │
                     ▼               ▼
                  直接跳过          进行缩放处理
                                1. 读取该行的 (x, y, z)
                                 2. 计算 D_SPO = √(x² + y² + z²)
                                 3. 计算 Scale = D_SDO / D_SPO
                                     │
                                     ▼
                        调出 缓存的 NetCDF 图像矩阵
                             [循环处理 N 个通道]
                                     │
                                     ▼
                               以中心为原点
                            按 Scale 放大/缩小
                                     │
                                     ▼
                           [ 画布自适应处理 ]
                     (放大时中心裁剪 / 缩小时边缘补零)
                                     │
                                     ▼
                        将元数据时间重写为当前未来时间
                                     │
                                     ▼
                         输出: 4096×4096 新 NetCDF

```
